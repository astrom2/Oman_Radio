# راديو عُمان

تطبيق أندرويد خفيف للاستماع لإذاعات سلطنة عُمان على الـ FM والإنترنت.

- **التنقل بالسحب**: اسحب على لوحة المحطة يميناً للتالية ويساراً للسابقة.
- **شاشة القفل والسماعة والسيارة**: زرّا التالي/السابق في إشعار التشغيل وشاشة القفل وأزرار البلوتوث تغيّر المحطة.
- **توفير البيانات**: يختار أقل معدل بت متاح لكل محطة، ويقطع الاتصال بعد دقيقة من الإيقاف المؤقت، ويخزّن قائمة المحطات أسبوعاً. خيار «توفير البيانات» يعرض المحطات ٦٤ kbps أو أقل فقط.
- مؤقت إيقاف، وعدّاد تقديري لاستهلاك الشهر، وإضافة محطة برابط مباشر (اضغط مطولاً عليها لحذفها).

- **إذاعات دولية**: مونت كارلو الدولية، راديو سوا (يفضّل نسخة الخليج)، الجزيرة (صوت القناة)، وBBC World Service.
- **موجات قصيرة HF**: الاستماع عبر شبكة أجهزة الاستقبال العامة KiwiSDR. يختار التطبيق أقرب مستقبِل متاح لعُمان، وللإشارات العالمية مستقبِلاً قرب المرسِل. يشمل بث BBC من محطة الإرسال في عُمان، وإذاعة الكويت، وصوت تركيا، والإذاعة الإيرانية العربية، ونطاقات الهواة 40 و20 متر، ومنارات NCDXF، وإشارات الوقت WWV وCHU، وشانون فولمت. أزرار ±1 و±5 كيلوهرتز للضبط الدقيق. مواعيد البث من دليل British DX Club للموسم B26.

قائمة المحطات تأتي من دليل [Radio Browser](https://www.radio-browser.info) المفتوح (المحطات المسجلة لعُمان).

## التنزيل
كل دفع إلى `main` يبني ملف APK موقّعاً ويضعه في صفحة **Releases** للمستودع.

## البناء محلياً
Android SDK + JDK 17 ثم:
```
gradle :app:assembleRelease
```
